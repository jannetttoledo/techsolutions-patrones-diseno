# TechSolutions

Proyecto de gestión empresarial para pymes desarrollado en Java con Spring Boot y Maven.

## Funcionalidades

- Procesamiento de pagos mediante PayPal, Yape y Plin.
- Control de acceso a reportes financieros.
- Alertas de stock bajo.
- Gestión de pedidos con historial y opción de deshacer.
- Estrategias flexibles para el cálculo de precios.
- Catálogo de productos con búsqueda y paginación.

## Patrones de diseño

- Adapter
- Proxy
- Observer
- Command
- Memento
- Strategy
- Iterator

## Requisitos

- JDK 17 o superior.
- Maven.
- NetBeans IDE, IntelliJ IDEA o Visual Studio Code.

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir el proyecto en el IDE.
3. Esperar que Maven descargue las dependencias.
4. Ejecutar la clase principal `TechsolutionsApplication`.
5. Abrir en el navegador:

```text
http://localhost:8080
```text
